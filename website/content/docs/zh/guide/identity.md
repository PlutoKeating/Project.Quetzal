## 身份是一份数据

一个 agent 的身份写在一份 `agent.json` 里，Quetzal 从这份文件读出 ta 是谁：

| 字段 | 含义 |
|---|---|
| `id` | UUID，诞生时生成，**永不改变**；用来防止两个 agent 的记忆混在一起 |
| `name` | 标识符（小写字母、数字、连字符） |
| `displayName` | 显示名，界面与称呼使用 |
| `pronouns` | 代词 |
| `description` | 一句简介 |
| `color` | 主题色 `#RRGGBB`，App 的界面颜色随之变化 |
| `language` | 偏好语言（BCP 47，如 `zh-CN`） |

## 在控制台里修改

**控制** 页最上面 ta 的名字那一行 → **身份**：改显示名、代词、简介、主题色、偏好语言（标识符不在这里改）。保存后写进 ta 的灵魂目录；接入了灵魂仓库时，这次修改作为一次提交同步到所有身体。

> [!TIP]
> 顶栏显示的名字、各处的称呼、主题色都来自这里。连接了多个 agent 时，切换到哪个 agent，界面就跟着变成 ta 的。

## 种子身份与种子人格

刚装好、还没起名字时，ta 有一份自动生成的**种子身份**（`seed: true`），和一份按这个身份生成的**种子人格**（`SOUL.md`）。「种子」表示还没有被改过：

- 你在 App 里一改名字，种子标记就去掉了；
- 接入一个**已经有别的身体住过**的灵魂仓库时，种子身份会**让位**：直接采用仓库里的身份与人格，并合并两边的记忆。

所以给一个已有的 agent 添加新身体时，**先接入灵魂仓库，再改身份**；全新的 agent 可以先起名字。

## 人格

人格写在 `SOUL.md` 里，是给模型的系统提示的第一段。你可以在 **记忆 → 核心** 里查看与编辑；ta 自己也能用 `rewrite_soul` 改写。这属于「改写记忆」这一类能力，你可以在授权里把它设为询问或禁止。

## 多个 agent

每个 agent 有自己的灵魂仓库与身份 id。同一台设备可以运行多个运行基座实例（各用不同的家目录与端口），App 能保存多个连接，一键切换。详见 [多个 agent](/docs/guide/multi-agent)。
