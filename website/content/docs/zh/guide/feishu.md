## 它能做什么

接入飞书后，ta 可以在飞书里和你说话。飞书里的操作都靠**交互卡片**上的按钮完成，不用记命令。

- 单聊自动推送**「此刻」卡片**：状态、驱动力、ta 想分享的一句话。
- 对话：发消息给机器人即可；ta 正在忙时你再发，默认作为插话并入这一轮。
- 卡片上的审批、授权、暂停、急停等按钮，和 App 里的同名操作效果一样。
- ta 醒来时的主动消息带「💭 主动消息」标识。

## 一键接入

**控制 → 飞书 → 连接飞书**：

```mermaid
sequenceDiagram
  participant U as 你
  participant A as 控制台
  participant R as 运行基座
  participant F as 飞书
  U->>A: 点「连接飞书」
  A->>R: feishu.register
  R->>F: 发起创建机器人
  F-->>R: 扫码 / 确认链接
  R-->>A: 推送链接（feishu.qr）
  U->>F: 在飞书中打开并确认
  F-->>R: 应用凭据
  R->>R: 保存（Secret 存在 secrets/），长连接上线
  R-->>A: 已连接，绑定你本人
  F->>U: 单聊收到「此刻」卡片
```

机器人用 agent 的显示名命名，并自动把点「连接飞书」的你绑定为所有者。接入用的是**长连接**，手机不需要公网地址。

> [!NOTE]
> 也可以手动填入已有应用的 App ID 与 App Secret（**控制 → 飞书 → 手动填写**）。Secret 保存在本机 `secrets/` 目录，不进灵魂仓库。

## 在飞书里对话

- 直接发消息，ta 在当前这一轮里回复。ta 正在忙时收到的消息，机器人先给它加一个表情表示收到，在下一次调用模型前并入这一轮。
- 发 **`/new [标题]`** 开启新会话。
- 发图片、文件：运行基座通过飞书的消息资源接口把它们下载下来，作为附件交给 ta。
- ta 向你要密码或密钥时，会发一张**保密输入**卡片（见 [保密传递](/docs/guide/secrets)）。飞书不允许机器人撤回你的消息，用完后请**自己撤回**含密钥的消息。

## 可选：机器人菜单

在飞书开发者后台「机器人 → 自定义菜单」里添加推送事件 `home` / `flow` / `memory` / `control`，聊天框底部就会出现菜单，点一下打开对应的卡片。

## 状态与排错

**控制 → 飞书** 里能看到连接状态、错误和所有者。常见问题见 [排错](/docs/advanced/troubleshooting)。
