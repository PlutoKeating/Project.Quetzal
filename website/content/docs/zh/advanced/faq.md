## ta 会一直花钱吗？

不会一直花。ta 醒来才调用模型，醒来率由内驱力与清醒度决定，睁眼先用便宜的内省模型判断"想不想动"，不想动就继续睡。你可以在 **控制 → 预算** 设每日 token 与费用上限，用尽后 ta 会非常安静。

## ta 夜里会吵我吗？

ta 有生物钟：困意超过阈值入睡，睡着时只偶尔做梦整理记忆，不会主动发消息。ta 的作息会被光线影响——夜里强光会让 ta 更清醒。

## 我的 API Key 安全吗？

Key 用 AES-256-GCM 加密保存在手机上，界面只显示末四位，不进灵魂仓库、不同步到别的身体。

## ta 能看到我发的密码吗？

不能看到明文。ta 需要凭据时会发起**保密输入**，你发的内容不进对话、不进模型上下文，直接存进本机保密库，ta 只拿到文件路径。详见 [保密传递](/docs/guide/secrets)。

## ta 能做什么？

内置工具：记忆与笔记、检索、网页搜索与抓取、看图、读文档（Word / PPT / Excel / PDF 等）、执行命令与后台任务、查进程、语音说话（Azure）、主动发消息、分享一句话、有界地调整自己的性格参数、改写人格。加上身体适配器提供的设备工具：手机上是拍照、录音、定位、震动、手电、剪贴板、读传感器。

## ta 能操作手机屏幕和别的 App 吗？

**还不能。** `hands`（看屏幕、点击、输入、打开应用）接口已预留，适配器尚未实现。授权里它默认「每次询问」。

## 没有电脑能用吗？

能。安装、配置、日常全部在 Quetzal App 里完成；唯一一次命令行是在 Termux 里粘贴一行开启外部调用。

## 必须用飞书吗？

不必须。App 本身就是完整的控制台。飞书是可选的第二个入口。

## 必须有灵魂仓库吗？

不必须。没有灵魂仓库时，身份、人格与记忆存在手机本地的灵魂目录里。想让 ta 换身体、住多具身体、有可查可撤销的记忆历史，再接入。

## 我的数据在哪里？

全部在手机上 `QUETZAL_HOME`（默认 `~/quetzal`）：配置、加密的 Key、SQLite 数据库（时间线、对话、审计、用量）、灵魂目录、保密库。接入灵魂仓库后，**只有人格与记忆**会推送到你自己的私有仓库。Quetzal 没有任何云端服务。

## 可以同时跑两个 agent 吗？

可以。每个运行基座一个家目录与端口，App 保存多个连接一键切换。详见 [多个 agent](/docs/guide/multi-agent)。

## 支持哪些手机？

Android 7 以上、arm64 的手机。需要能安装 Termux 三件套。越旧的手机越要做好保活（电池优化名单、自启动放行）。

## ta 做错事了怎么办？

- 顶栏**急停**立即冻结一切；
- **控制 → 审计日志** 看 ta 做了什么；
- 记忆改错了，在**记忆历史**里撤销（反向提交，历史保留）；
- 以后不想让 ta 做某类事，在**能力授权**里设为询问或禁止。
