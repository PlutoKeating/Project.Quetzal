## ta 会一直花钱吗？

ta 只在醒来时调用模型。醒来后先用便宜的模型判断想不想动，不想动就继续睡。在 **控制 → 高级 → 预算** 设每天的 token 与费用上限；到了上限，ta 自己醒来的次数降到原来的二十分之一，你找 ta 说话不受影响。

## ta 夜里会吵我吗？

ta 有生物钟：困意超过阈值就入睡，睡着时只偶尔做梦整理记忆，不主动发消息。光线也影响作息，夜里的强光会让 ta 更清醒。

## 我的 API Key 安全吗？

Key 用 AES-256-GCM 加密，保存在运行基座所在的设备上。界面只显示末四位；Key 不进灵魂仓库，也不同步到别的身体。

## ta 能看到我发的密码吗？

看不到明文。ta 需要凭据时会发起**保密输入**：你发的内容直接存进本机保密库，不进对话和模型上下文，ta 只拿到文件路径。详见 [保密传递](/docs/guide/secrets)。

## ta 能做什么？

内置工具：记忆与笔记、检索、网页搜索与抓取、看图、读文档（Word / PPT / Excel / PDF 等）、执行命令与后台任务、查进程、语音说话（Azure）、主动发消息、分享一句话、有界地调整自己的性格参数、改写人格、造自己的工具、开子 agent。设备另外提供工具：手机上是拍照、录音、定位、震动、手电、剪贴板、读传感器；电脑（Linux、Windows）上是拍照、录音、截屏、剪贴板、打开文件与网址。

让 ta 提醒你的事，到点会准时提醒。用一个月之后 ta 会是什么样，见 [一个月后](/docs/start/first-month)。

## ta 会不会乱来？

ta 能运行命令，「执行命令」默认允许。命令在隔离环境里运行，看不到密钥。这层隔离挡不住所有情况，也确实出过一次越界。请给 ta 一部专门的设备；想收紧，把「执行命令」改成「询问」。详见 [信任与边界](/docs/guide/trust)。

## ta 能操作手机屏幕和别的 App 吗？

**还不能。** `hands` 接口（看屏幕、点击、输入、打开应用）已经预留，适配器还没有实现。授权里它默认「每次询问」。

## 没有电脑能用吗？

能。只装 Quetzal App 一个应用，打开它就自动安装。安装、配置、日常使用都在 App 里完成，全程不用命令行。

## 只有一台电脑、没有闲置手机，能用吗？

能。电脑或服务器也可以做 ta 的身体：

- **Linux**：运行 `curl -fsSL https://quetzal.plutokeating.beer/install | bash`。缺的依赖自动补齐，开机自启、崩溃自动重启，应用列表里多一个 Quetzal。网页控制台在浏览器里打开即登录（同一台机器免配对码），配置与对话都在里面。见 [Linux 与其他机器](/docs/advanced/other-machines)。
- **Windows 10（1809 起）或 Windows 11**，x64 或 arm64：在 PowerShell 里运行 `irm https://quetzal.plutokeating.beer/install.ps1 | iex`，或者下载安装包双击。重启后不登录也在后台运行，登录后托盘里有 Quetzal。见 [Windows](/docs/advanced/windows)。

电脑这具身体的感官没有手机丰富，通常没有光线与运动传感器。桌面版控制台可以当耳朵，但没有回声消除：ta 说话时不收音。网页版控制台没有麦克风。

## 必须用飞书吗？

不必须。App 本身就是完整的控制台，飞书是可选的第二个入口。

## 必须有灵魂仓库吗？

不必须。登录并批准设备时，会自动在你的 GitHub 账号下建一个私有灵魂仓库；跳过登录，身份、人格与记忆就存在设备本地。以后想让 ta 换设备、住进几台设备、有可查可撤销的记忆历史，再登录，或者在 **控制 → 高级 → 同步** 手动接入你自己建的仓库。

## 我的数据在哪里？

- **你的设备**：配置、加密的 Key、数据库（时间线、对话、操作记录、用量）、灵魂目录、保密库。
- **你 GitHub 上的私有灵魂仓库**：人格、记忆、日记、笔记、工具说明书。
- **你选的模型供应商**：每次对话和醒来思考的内容。
- **同步服务**：作者个人运营，登录和几台设备互连时默认使用，账号是 PlutoKeating 账号（作者的统一账号）。它登记你的账号（用户名、邮箱）、agent 和设备，看不到对话与记忆。第一次建灵魂仓库时安装的 GitHub 应用能管理你选中的仓库，同步服务只在你批准设备的那一刻用它。

每一方能做什么、怎么收回，见 [信任与边界](/docs/guide/trust)。

## 更新这么快，ta 的记忆会丢吗？

不会。记忆是你仓库里的 Markdown 文件，格式改过 12 次，旧仓库都不用转换；每次改动都是一次提交，可以撤销。更新由你点确认。有两点要留意：几台设备要升到同一个版本才能互连；对话记录只在设备上，卸载 App 会删掉。详见 [信任与边界](/docs/guide/trust#更新有多快)。

## 可以同时跑两个 agent 吗？

可以。每个运行基座用自己的家目录与端口，App 保存多个连接，可以一键切换。详见 [多个 agent](/docs/guide/multi-agent)。

## 支持哪些手机？

Android 7 以上、arm64 的手机，能装 Quetzal App 就行。手机越旧，越要做好保活（电池优化名单、自启动放行）。最好用一部专门给 ta 的手机。

## ta 做错事了怎么办？

- 顶栏**急停**立即冻结一切；
- **控制 → 高级 → 操作记录** 看 ta 做了什么；
- 记忆改错了，在 **控制 → 高级 → 记忆历史** 里撤销（反向提交，历史保留）；
- 以后不想让 ta 做某类事，在 **控制 → 权限** 里设为询问或禁止。
