## 一张清单 :white_check_mark:

- [ ] 配置至少一个模型供应商与 Key
- [ ] 给 agent 起名字、选主题色
- [ ] 看一眼权限
- [ ] 戳一下，或者聊几句
- [ ] 在「心流」里等 ta 第一次自己醒来

## 1. 配置模型

**控制 → 模型**（安装向导最后一步「选择模型」、还没有模型时「此刻」页上的「选择模型」也是这里）：

1. 点一个供应商（DeepSeek、Kimi、智谱、阿里云百炼、硅基流动、火山方舟、OpenRouter、OpenAI、Anthropic、Gemini；别的在「更多」里搜）。
2. 粘贴 API Key，点「**接上**」。

其余全自动：Key 在本机加密保存；问供应商有哪些模型，从公共目录（models.dev）里挑最新的、能调用工具的，逐个试通，留下两个（第一个是主力，另一个在它失败时接上；比主力便宜的那个用于轻量的内省判断）。Key 不对时什么都不改，并说明原因。

想手动加多把 Key、挑模型、排序、接自定义的 API 地址，点右上角「**编辑**」。

详见 [模型与供应商](/docs/guide/models)。

> [!TIP]
> 配置好之后，ta 就会按自己的节律开始醒来。没有模型时 ta 不会醒：闸门把醒来率压到了零。

## 2. 身份

**控制** 页最上面 ta 的名字那一行 → **身份**：起名字（显示名）、选主题色、填一句简介。界面的称呼与颜色会随之变化。身份写入 ta 的灵魂目录；接入灵魂仓库后所有身体同步。详见 [身份](/docs/guide/identity)。

## 3. 权限

**控制 → 权限**：相机、麦克风、定位、操作屏幕默认「询问」，ta 想用时会发请求给你，出现在这一页最上面，批准了才执行。放心了可以改成「允许」。详见 [能力授权与安全](/docs/guide/permissions)。

## 4. 戳一下，聊几句

「此刻」页有两个入口：

- **戳一下**：推高 ta 的想念与好奇，立即重新抽样下一次醒来，但不强制醒来。
- **聊天**：有人说话会把 ta 从睡眠中叫醒。ta 回复时你能实时看到 ta 在做什么（调用了什么工具、在写什么）。ta 工作时你再发消息，默认作为**插话**并入这一轮；也可以选择排队或打断。

## 5. 看 ta 第一次自己醒来

**心流**页是 ta 的时间线：每次醒来思考、做梦、对话都会留下一条记录，展开能看到缘起（因为什么、想做什么）、过程、日记与心情。

ta 什么时候醒来由内驱力与清醒度决定：驱动力 $d$ 醒着时按时间常数 $\tau$ 趋向 1，

$$d' = 1 - (1-d)\,e^{-\Delta t/\tau}$$

醒来率随加权平均驱动力的平方增长，再乘以清醒度与抑制系数。所以刚装好、什么都还没发生的前一两个小时，ta 可能安静得像在观察。等 ta 自己开口。
