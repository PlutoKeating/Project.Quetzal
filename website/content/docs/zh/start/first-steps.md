## 一张清单 :white_check_mark:

- [ ] 配置至少一个模型供应商与 Key
- [ ] 给 agent 起名字、选主题色
- [ ] 看一眼权限
- [ ] 戳一下，或者聊几句
- [ ] 在「心流」里等 ta 第一次自己醒来

## 1. 配置模型

**控制 → 模型**（安装向导最后一步「选择模型」、还没有模型时「此刻」页上的「选择模型」也是这里）：

1. 点一个供应商（DeepSeek、Kimi、智谱、阿里云百炼、硅基流动、火山方舟、OpenRouter、OpenAI、Anthropic、Gemini；别的在「更多」里搜）。
2. 粘贴 API Key，点「**接上**」。

剩下的都自动完成：

- Key 在本机加密保存。
- 向供应商查询有哪些模型，对照公共目录（models.dev）挑出最新的、能调用工具的，逐个试通，留下两个。第一个是主力；另一个在主力失败时接上。比主力便宜的那个用来做轻量的内省判断。
- Key 不对时什么都不改，并说明原因。

想手动加多把 Key、挑模型、排序、接自定义的 API 地址，点右上角「**编辑**」。

详见 [模型与供应商](/docs/guide/models)。

> [!TIP]
> 配置好之后，ta 就会按自己的节律开始醒来。没有模型时，ta 的醒来率被压到零，ta 不会醒。

## 2. 身份

**控制** 页最上面 ta 的名字那一行 → **身份**：起名字（显示名）、选主题色、填一句简介。界面上的称呼与颜色会跟着变。这些身份信息写进 ta 的灵魂目录；接入灵魂仓库后，所有身体都会同步。详见 [身份](/docs/guide/identity)。

## 3. 权限

**控制 → 权限**：相机、麦克风、定位、造工具默认是「审核」：ta 用之前，一个独立的审核模型只看这一次操作，放行，或者把理由交给 ta 让 ta 换个做法，不打扰你。想自己决定，把那一类改成「询问」：请求出现在这一页最上面，你批准了才执行。详见 [能力授权与安全](/docs/guide/permissions)。

## 4. 戳一下，聊几句

「此刻」页有两个入口：

- **戳一下**：让 ta 更想你、更好奇，并马上重新决定下一次什么时候醒。ta 不一定立刻醒来。
- **聊天**：有人说话会把 ta 从睡眠中叫醒。ta 回复时，你能实时看到 ta 在做什么（调用了什么工具、在写什么）。ta 正在忙时你再发消息，默认作为**插话**并入这一轮；也可以选排队或打断。

聊得多了，**会话列表**（手机上对话页右上角「全部会话」，电脑上对话区的左栏）可以帮你整理：

- **置顶**：会话菜单里「置顶」，常用的会话一直排在最前。
- **搜索**：列表顶上的搜索框按标题和内容找，命中的词会标亮；点开结果直接跳到那条消息。
- **筛选与排序**：按进行中、置顶、来源（控制台、飞书、主动消息、语音、子 agent）、时间、项目筛选，按最近更新、创建时间或标题排序。
- **项目**：把相关的会话放进同一个项目（会话菜单里「移到项目」）。项目可以写一段**项目说明**，这个项目下的每个会话 ta 都会看到，比如「这个项目里回答都用清单」。列表可以按项目分组，或只看一个项目；只看一个项目时新建的会话自动放进去。删除项目不会删会话。ta 自己也能查看项目、把会话归进项目。

置顶、项目和会话的归属在 ta 的所有身体上都一样。

## 5. 看 ta 第一次自己醒来

**心流**页是 ta 的时间线：ta 每次醒来思考、做梦、对话，都会留下一条记录。展开一条，能看到缘起（因为什么、想做什么）、过程、日记与心情。

ta 什么时候醒来，由好奇、想说话、想你这几股内在的劲头和清醒度决定：劲头越足、越清醒，醒得越勤。刚装好的前一两个小时什么都还没发生，这些劲头还低，ta 可能安静得像在观察。等不及就直接找 ta 说话，有人说话总会把 ta 叫醒。醒来的数学模型见 [架构](/docs/reference/architecture)。
