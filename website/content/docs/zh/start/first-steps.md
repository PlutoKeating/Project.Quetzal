## 一张清单 :white_check_mark:

- [ ] 配置至少一个模型供应商与 Key
- [ ] 给 agent 起名字、选主题色
- [ ] 看一眼能力授权
- [ ] 戳一下，或者聊几句
- [ ] 在「心流」里等她第一次自己醒来

## 1. 配置模型

**控制 → 模型**：

1. **添加供应商**：从目录选择（目录来自 models.dev，带上下文长度与价格），或自定义 API 地址与协议（OpenAI 兼容、OpenAI Responses、Anthropic Messages、Google Gemini 四种）。
2. **添加 Key**：Key 在本机加密保存，界面只显示末四位。
3. **勾选模型** → **保存** → **测试连通**。
4. 在**「全局模型顺序」**里拖动排序。排在前面的先用，失败自动切到下一个。
5. 可选：把一个便宜、快的模型设为**「内省」模型**，用于她醒来时"想不想动"的轻量判断。

详见 [模型与供应商](/docs/guide/models)。

> [!TIP]
> 配置好之后，她就会按自己的节律开始醒来。没有模型时她一直不会醒——这是闸门的抑制，不是故障。

## 2. 身份

**控制 → 身份**：起名字（显示名）、选主题色、填一句简介。界面的称呼与颜色会随之变化。身份写入她的灵魂目录；接入灵魂仓库后所有身体同步。详见 [身份](/docs/guide/identity)。

## 3. 能力授权

**控制 → 能力授权**：相机、麦克风、定位、操作屏幕默认「每次询问」，她想用时会发审批给你，批准了才执行。放心了可以改成「允许」。详见 [能力授权与安全](/docs/guide/permissions)。

## 4. 戳一下，聊几句

「此刻」页有两个入口：

- **戳一下**：推高她的想念与好奇，立即重新抽样下一次醒来——但不强制醒来。
- **聊天**：有人说话会把她从睡眠中叫醒。她回复时你能实时看到她在做什么（调用了什么工具、在写什么）。她工作时你再发消息，默认作为**插话**并入这一轮；也可以选择排队或打断。

## 5. 看她第一次自己醒来

**心流**页是她的时间线：每次醒来思考、做梦、对话都会留下一条记录，展开能看到缘起（因为什么、想做什么）、过程、日记与心情。

她什么时候醒来由内驱力与清醒度决定：驱动力 $d$ 醒着时按时间常数 $\tau$ 趋向 1，

$$d' = 1 - (1-d)\,e^{-\Delta t/\tau}$$

醒来率随加权平均驱动力的平方增长，再乘以清醒度与抑制系数。所以刚装好、什么都还没发生的前一两个小时，她可能安静得像在观察。等她自己开口。
