---
title: 一个月后
description: 装好之后的第一天、第一周、第一个月，ta 会做什么、记下什么，你在哪里能看到。
---

ta 对你有多少用，取决于 ta 记得多少、记得对不对。这一页按时间顺序讲 ta 会做的事，以及每一步你在哪里能亲眼看到。这里写的是 ta 的工作方式，例子都是虚构的。

## 第一天

你配好模型，聊几句。

- ta 把关于你的事记进 `memories/USER.md`：你的名字、你提到的工作、你说过不喜欢的东西。ta 自己的笔记记进 `memories/MEMORY.md`。
- 每次自己醒来、每次做梦之后，ta 写一段日记，放在 `journal/<设备>/<日期>.md`。
- 这些文件一写下就提交到你的私有灵魂仓库。在 GitHub 上打开仓库，就能读到 ta 写了什么。

刚装好的头一两个小时，ta 可能很安静。ta 醒来的频率取决于好奇、想说话、想你这些内在的驱动，刚开始还没有积累起来。

## 第一周

- **每晚做梦。** ta 困了就睡，睡着时回顾这几天的日记和对话，把零散的细节整理成笔记（`notes/` 下按主题分目录），合并重复的，改掉记错的，再写一篇「梦」的日记。
- **说话前先翻笔记。** 你每说一句，ta 会按关键词在笔记、日记和常驻记忆里找相关的内容，带着它们回答。你问「我上次说想换的那个工作」，ta 能找到那条笔记。
- **自己醒来找你。** ta 醒着时想到了什么，会主动发消息给你，出现在 App 的「主动消息」里，并弹一条通知；接了飞书的话也发到飞书。

## 第一个月

- **几十篇日记。** 「心流」页列着 ta 每一次醒来、思考、做梦、对话，展开能看到起因和过程。
- **自己的工具。** 同一件事做过几次，ta 会想把它写成自己的工具，以后一步做完。造工具默认先问你；工具的说明书存进灵魂仓库的 `skills/`。
- **调整自己。** 你说「你最近太吵了」，ta 会有界地调低自己醒来的倾向；说「说话慢一点」，ta 会调语速。

## 你随时能做的

- **读。** 灵魂仓库里的一切都是 Markdown 文件。想知道 ta 认识的你是什么样，打开 `memories/USER.md`。
- **改。** 记错了就告诉 ta，ta 会改；也可以直接在 GitHub 上编辑文件，ta 下次醒来会同步到。
- **撤销。** **控制 → 高级 → 记忆历史** 列出每一次改动，点撤销会生成一次反向提交。
- **让 ta 提醒你。** 说「明早 8 点提醒我吃药」或「每周一 9 点提醒我开会」，ta 记下后，到点由基座准时发通知，ta 醒着、睡着都一样。不急的事说「这两天找个时间提醒我还书」，ta 会等你在身边的时候（拿起手机、刚找过 ta）再提，并说明为什么挑这时候，夜里不打扰。**此刻** 页列着接下来的提醒，点叉取消。
- **翻旧话。** 检索覆盖所有会话的对话、笔记和日记。问「上周说的那家店叫什么」，ta 先把「上周」换成具体日子，再在那几天里找。

## ta 做不到的

- **不会操作别的 App。** 看屏幕、点按钮的能力还没有做。
- **关机太久会错过提醒。** 提醒要靠运行着的基座发出。设备关机或基座停了，12 小时以内的会在恢复后补发并写明晚了多久，更早的不再补发，ta 会告诉你错过了哪条。
- **几台设备断开时，同一条提醒可能响两次。** 有几台设备时只由一台负责提醒；它们之间断开时各自都会负责。

## 一个月要花多少

ta 醒来先用便宜的模型判断想不想动，不想就接着睡，所以大部分醒来花费很少。**控制 → 高级 → 预算** 设每天的 token 与费用上限（默认 200 万 token、5 美元）。到了上限，ta 自己醒来的次数会降到原来的二十分之一；你找 ta 说话不受影响。
