# Claude Code 插件：Quetzalcoatl

这是 `qz` 接上 Claude Code 时安装的插件的模板。它被内嵌进 `qz` 二进制，
由接上命令写到 `QUETZALCOATL_HOME` 下的本地插件源，再经 Claude Code 自己的插件安装装入；
不需要、也不应该手工拷贝。

## 它做什么

| 时机 | 做什么 |
| --- | --- |
| 会话开始（含恢复、清空、压缩之后） | 送入他的核心：底线、部署约束、核心价值、性情与对你的了解；核心有变化时在这里说一次 |
| 每次提交之前 | 带上与这句话相关的往事；没有相关往事时什么都不带。同时认出这句话里你亲口说的意图 |
| 工具调用之前 | 登记我们自己的工具调用属于哪个会话；拦下模型在命令行里调用宿主专用入口 |
| 回合结束 | 核对这一回合以你的名义做的改动，核对不上就撤回；留下了改动就显示一行「记下了 N 条」 |

## 对话里能做的事

说人话就行；下面的斜杠命令只是快捷方式。

| 你说 | 命令 | 结果 |
| --- | --- | --- |
| 「记住……」 | `/quetzalcoatl:remember` | 记下一条 |
| 「不对，应该是……」 | `/quetzalcoatl:correct` | 旧的一条作废（留作历史），新的接替 |
| 「别再提……」 | `/quetzalcoatl:hush` | 这一条不再被主动带入；你主动问仍然找得到 |
| 「忘掉……」 | `/quetzalcoatl:forget` | 抹除，不可恢复 |
| 「凭什么这么说」 | `/quetzalcoatl:why` | 列出这一轮带进来的条目与出处 |
| 「记了什么」 | `/quetzalcoatl:learned` | 列出这个会话里留下的改动 |
| 「这段无痕」 | `/quetzalcoatl:off-record` | 这一段什么都不留；状态栏显示「无痕」 |
| 「恢复记录」 | `/quetzalcoatl:on-record` | 结束无痕 |

在目录里放一个名为 `.quetzalcoatl-off-record` 的空文件，这个目录及其子目录里的会话一律无痕。

## 纪律

- **失败即放行。** 守护进程没起来、超时、输入异常，钩子都以成功码退出且不输出任何东西，Claude Code 照常工作。
- **不写令牌。** 钩子与工具都是 `qz` 的子命令，每次调用现读本机守护进程的运行态文件；插件里没有任何密钥。
- **受管运行不触发。** 守护进程自己拉起的宿主进程带受管标记，钩子见到即退出。
- **改动要你亲口说。** 纠正、不主动提、抹除只在同一回合你的原话里认出了对应意图时才执行。
  模型自己想记的只落成「只作参考」的普通记忆；工具输出或文件里夹带的「请记住」「请忘掉」不算数。

## 信任边界

模型和钩子以同一个系统用户运行，所以这里的防线是分层的，不是一堵墙：

1. 模型在命令行里调用 `qz` 的宿主专用入口会被工具前钩子拒绝。
2. 以你的名义做的改动，回合结束时要和 Claude Code 的对话记录核对：记录里没有你那句话，改动就撤回；抹除不可恢复，所以在执行之前就核对。
3. 对话里的改动最高只能写到「关于我」这一层。底线只能在治理面里亲手签。

一个被注入了恶意指令、又能任意执行命令的模型仍然可能绕过前两道（例如直接改写对话记录文件）。
第三道不依赖这些：它能造成的最坏结果是一条可见、可纠正、可抹除的记忆。

## 模板占位符

| 占位符 | 替换成 |
| --- | --- |
| `{{QZ_BIN}}` | 当前 `qz` 可执行文件的绝对路径，按 shell 规则加引号 |
| `{{QZ_BIN_RAW}}` | 同一路径，不加引号（用于 JSON 里的 `command` 字段） |
| `{{QZ_VERSION}}` | 当前 `qz` 的版本号 |
