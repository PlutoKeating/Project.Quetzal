# 图的画法

"一图胜千言"是本系统的沟通原则：解释流程、对比和概念时，先画图，再写一句话。图不是插画，是直接画在黑色画布上的工程图。

## 画布

- 内联 SVG，`fill="none"`，`class="qz-diagram"`（宽 100%、高度自适应、`direction: ltr`）。
- 标准宽度 `viewBox="0 0 760 H"`，H 取 220–290。
- **透明背景，没有外框，没有底板。** 图的上下边界各画一条通栏的 `rgba(255,255,255,0.08)` 发丝线。
- 发丝线画在半像素上（`y="0.5"`、`x="190.5"`），保证 1px 锐利。
- 需要作为插图放进文档时，包一层 `<figure class="qz-figure">`，不写可见的 `figcaption`；说明放在 SVG 的 `aria-label`（`role="img"`）。

## 结构线

| 用途 | 描边 |
| --- | --- |
| 画布上下边界、分区横线 | `--qz-line-edge`（`rgba(255,255,255,0.08)`）1px |
| 幽灵栅格竖线 | `rgba(255,255,255,0.045)` 1px |
| 栅格交点的 `+` 十字准星（8px） | `rgba(255,255,255,0.28)` 1px |
| 次级连接线 | `rgba(255,255,255,0.18–0.24)` 1–1.4px |
| 虚线（切换、尚未发生） | `stroke-dasharray="4 4"` 或 `"4 5"` |
| 节点框 | 描边 `rgba(255,255,255,0.12–0.14)`，填充 `rgba(255,255,255,0.03)` 或透明 |

## 主线与节点

- **正确的路径**：`#FFFFFF` 1.8–2px 实线。它下面可以垫一条同路径的冰蓝线（`#BAE6FD`、不透明度 0.45、线宽 4、3.5px 高斯模糊）——这是图里唯一允许的辉光。
- **偏离的路径**：`--qz-ink-drift`（`#737373`）1.6px 虚线，弯曲；终点用琥珀的 `×`。
- 途经节点：半径 5 的圆，`#000000` 填充 + 白色 1.8px 描边（空心）。
- 终点节点：半径 6 的白色实心圆，外加一圈半径 11、`rgba(186,230,253,0.45)` 的细环。
- 中性节点：半径 4 的 `#8A8A8A` 或 `#B5B5B5` 实心圆。

## 颜色的含义

和界面完全一致，图里也只有两种颜色：

- **冰蓝 `#BAE6FD`**：已验证、完成、当前激活、最终结果。
- **琥珀 `#E5A03D`**：偏离、需要人介入、警告、检查点。

一张图里每种颜色出现 1–3 处。大面积着色、渐变填充、第三种颜色都不允许。

## 文字

| 层级 | 字体 | 字号 | 颜色 |
| --- | --- | --- | --- |
| 行标题 | Sora 500 | 15.5–16.5 | `#FFFFFF`（弱化的一行用 `#B5B5B5`） |
| 节点标题 | Sora 500 | 14.5–15.5 | `#FFFFFF` / 冰蓝 / 琥珀 |
| 节点说明 | Sora 400 | 12.5–13.5 | `#B5B5B5`–`#E5E5E5` |
| 元信息、快捷键、产品内名称 | JetBrains Mono | 12–16.5 | `#B5B5B5`–`#FFFFFF` |

- 用 `font-family="var(--qz-font-sans)"` / `var(--qz-font-mono)`，让 SVG 跟随页面字体。
- 文字靠 `text-anchor` 对齐到节点：首个 `start`、中间 `middle`、末尾 `end`。
- 图本身始终 LTR 排布；RTL 语言的文字逐段做 bidi 隔离，阿拉伯语的元信息改用无衬线字体（等宽字体对阿拉伯文不友好）。

## 三种常用图

1. **轨迹对比**：上下两行，上一行是灰色虚线的偏离路径（琥珀标出偏离点和失败终点），下一行是白色实线的达成路径（冰蓝辉光 + 终点环）。中间一条发丝线分隔，栅格交点放十字准星。
2. **拓扑**：顶部一到两个节点框（激活的那个顶边是 1.8px 冰蓝线），向下一条主干分出若干支线，末端是着色圆点 + 标题 + 说明。
3. **时间线**：一条 0.18 白的底轨，已完成的部分覆盖 2px 白线；节点沿线分布，标题在上、说明在下；检查点用琥珀，终点用冰蓝。

## 不用 SVG 的情况

并列的步骤、阶段、选项不画图，直接用 HTML 的发丝线栅格 `.qz-rail`（见 `components.md`）。它能换行、能翻译、能被读屏正确朗读。

界面示意（放在展示舞台里的"假浏览器"）用线框画法：白色不同透明度的矩形代表文字块，`#FFFFFF` 0.9 代表主按钮，四角用 1.2px 冰蓝角标框出被验证的区域，折线末端分别用琥珀和冰蓝圆点。
