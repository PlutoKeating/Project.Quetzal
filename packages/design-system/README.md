# Quetzalcoatl design system

> 五彩斑斓的黑。

> **本目录是 Quetzalcoatl 产品仓库里设计系统的唯一副本。** 界面改动先改这里，再由官网与各端引用；不在产品代码里重述数值。

Quetzalcoatl 是我们的企业品牌设计系统。它的全部视觉语言来自一句话：**在纯黑的背景上，存在一层不扎眼的光——像自然阳光照在一块 OLED 屏幕上衍射出来的光晕。**

页面本身是绝对的黑，没有灰色卡片，没有彩色色块。光只以两种方式出现：一片固定在视口里、几乎察觉不到的冰蓝与钨丝琥珀色光晕；以及物体边缘接住这片光时出现的 1px 高光线。内容在光上滑过，光自己不动。

**来源：** 本系统从已上线的 UltraCode 官网（`https://ultracode.plutokeating.beer`，源码 `Project.UltraCode/website/`）逐条提取而来，所有数值都是线上实际生效的值，不是事后设想。UltraCode 中的 `--uc-*` 变量和 `.uc-*` 类在这里统一改名为 `--qz-*` 和 `.qz-*`，数值不变。

此前的 Quetzalcoatl（"Ten O'Clock Sun"：炭灰底、暖象牙纸、Archivo、实体按键）已整体废弃，本目录不保留其任何内容。

## 艺术方向：Precision Cinema Monochrome

五个特征让这套系统一眼可认：

1. **96 / 4。** 每一屏 96% 的面积严格零饱和度（S = 0%）：`#000000` 的底、白色的字、白色低透明度的线。剩下 4% 是光：冰蓝 `#BAE6FD` 和钨丝琥珀 `#E5A03D`，除此以外没有第三种颜色。
2. **光有来处，而且不动。** 一片固定在视口的"光学地平线"是唯一光源。页面元素靠近它时变亮、边缘出现高光，远离时暗下去。没有悬浮发光，没有彩色阴影。
3. **发丝线，不是盒子。** 分组靠 1px 白色低透明度的线、十字准星和留白完成。不存在灰色卡片、描边卡片、圆角容器堆叠。
4. **字重 500 的大标题。** 标题从不加粗。尺寸感来自紧的负字距（-0.04em）和纯白，而不是笔画粗细。
5. **唯一的实心是白色。** 主操作是一块纯白按钮，黑字。它是画面上最亮的东西，一屏只有一个。

## 设计原则

1. **黑就是黑。** 页面底色永远是 `#000000`，不抬成深灰，不加渐变底。层次只靠 `#070707`、`#0A0A0A`、`#0E0E0E` 这几级几乎不可见的抬升。
2. **光是稀缺资源。** 光晕不透明度上限：冰蓝 0.14、琥珀 0.11。高光线永远 1px。只有 6px 的 LED 圆点可以自发光。想加更多光时，答案是不加。
3. **颜色即语义。** 冰蓝表示"已验证、进行中、自动、成功"；琥珀表示"人在说话、需要人介入、偏离、手动"。没有绿色、红色、蓝色。颜色从不用来装饰。
4. **一图胜千言。** 概念先用直接画在黑底上的 SVG 图解释，其次才是一句话的说明。
5. **只有透明度在动。** 过渡只作用于颜色、边框和不透明度，120–180ms。没有位移、缩放、弹跳，没有入场动画。
6. **安静的密度。** 段落行高 1.7–1.85，段间距 2rem，区块间距 7.5rem。宁可留白也不填满。
7. **任何人都能读。** 正文对比度不低于 4.5:1，所有控件有可见焦点，颜色从不作为唯一信号（冰蓝/琥珀状态必须同时带文字或位置区分）。

## 内容基础

- **语气：** 平静、确定、现在时。说产品为用户做了什么，不说内部实现。不出现文件名、配置键、变量名。
- **大小写：** 标题、按钮、标签一律句首大写。全大写只用于等宽状态词（`AUTO`、`MANUAL`）。
- **数字：** 永远用阿拉伯数字，开启 `tabular-nums`。步骤编号用等宽两位数（`01`、`02`）。
- **命令与代码：** 永远等宽、永远 LTR，即使页面是 RTL。
- **多语言：** 支持 CJK、阿拉伯语（RTL）、西里尔字母。阿拉伯语标题取消负字距并把行高放到 1.28。全部用逻辑属性（`inline-start` / `inline-end`）。
- **标点：** 界面里不用感叹号，不用 emoji。并列项用间隔号 `·` 连接。
- **不编造：** 没有的客户 logo、评价、跑分数字就不放。

**字标光谱（唯一的例外）。** 品牌名或所有者名的字标可以带六条横向色带，仅此一处，不承载任何含义，也不得用于其他文字、图形或状态。

| 色带 | Token | 值 |
| --- | --- | --- |
| 绿 | `--qz-spectrum-1` | `#69DD4A` |
| 黄 | `--qz-spectrum-2` | `#F9D343` |
| 橙 | `--qz-spectrum-3` | `#FFAC61` |
| 红 | `--qz-spectrum-4` | `#FF8D88` |
| 紫 | `--qz-spectrum-5` | `#DE87FE` |
| 蓝 | `--qz-spectrum-6` | `#2FC4FF` |

六个值**故意不共用同一亮度和浓度**，而是按人眼的感知逐个校准：

- 人眼灵敏度峰值在 555 nm 附近，绿和黄天然最亮，所以它们停在低于自身上限的亮度；红和紫处在灵敏度低的波段，被提亮。
- 高饱和的蓝、紫、红看起来比实际亮度更亮（Helmholtz–Kohlrausch 效应），判断"是否等亮"时已计入这一点。六条色带校正后的感知亮度相差约 12 个点。
- 每条色带都贴着它所在亮度的 sRGB 最大浓度。往色域内部收的颜色，在白色标题旁会显得发灰；黄色低于约 85 的亮度会变成芥末色。
- 在广色域屏幕（`color-gamut: p3`）上，橙、红、紫、蓝在亮度不变的前提下获得更高浓度。

调整其中一条时必须和另外五条一起重新比对，不要单独改。

线条全部是白色的低透明度，按强度分九级（0.045 → 0.42），完整列表见 `tokens/colors.css`。交互填充同理是白色的 0.035–0.10。

### 光学（本系统的核心）

全部定义在 `tokens/optics.css`，滚动响应在 `scripts/optics.js`。

- **光学地平线。** 一个 `position: fixed; inset: 0` 的层，画两个极宽极扁的径向渐变：冰蓝在左（32%），琥珀在右（70%），都落在视口高度 58% 处，分别衰减到 72% / 74% 透明。沉浸式页面用 `48% 24%` 和 `42% 22%` 的椭圆、0.14 / 0.11 的不透明度；阅读页面用更高更柔的 `55% 38%` 和 `48% 34%`、0.13 / 0.10，位置上移到 48% / 46%。
- **胶片颗粒。** 整页最上层（z-index 60）覆盖一层单色 `feTurbulence` 噪点，不透明度 0.024。它让纯黑不发死，不带任何色偏。
- **高光线。** 永远 1px，水平渐变：透明 → 冰蓝 → 白 → 琥珀 → 透明。四个强度：区块顶边 `--qz-specular-seam`、舞台顶沿 `--qz-specular-rim`、标题与正文之间 `--qz-specular-quiet`、阅读页 h2 下划线 `--qz-specular-rule`。
- **滚动耦合。** 元素离地平线越近越亮：区块正文不透明度在 0.76–1.0 之间，区块顶边高光在 0–1 之间，舞台顶沿在 0.32–1.0 之间，阅读页 h2 下划线在 0–0.8 之间。只改不透明度，用 `requestAnimationFrame` 节流；`prefers-reduced-motion` 下完全停用，页面保持全亮静态。
- **自发光。** 只有 6px 的冰蓝 LED 圆点和激活的 5px 方形刻度可以带 `0 0 8px rgba(186,230,253,0.8)` 的光。SVG 中只有"正确路径"那一条线可以垫一层 3.5px 高斯模糊的冰蓝。
- **烟熏玻璃。** 展示舞台是 `rgba(12,12,12,0.86) → rgba(6,6,6,0.94) → 透明` 的纵向渐变加 20px 背景模糊，只有顶部两个 10px 圆角，底部用 `mask-image` 从 76% 处淡出，溶回黑色。
- **不透明的侧栏。** 文档侧栏是不透明的纯黑，光照不到它；光只落在正文区域。

### 字体

- **Sora**（显示 + 界面），字重 400 / 500 / 600。500 用于一切标题和按钮；600 只用于字标和编号圆点。**不使用 700 及以上。**
- **JetBrains Mono**（技术），字重 400 / 500。用于命令、代码、编号、状态词、元信息。
- CJK 回落到 PingFang SC / Hiragino Sans GB / Noto Sans SC / Microsoft YaHei；阿拉伯语回落到 Geeza Pro / SF Arabic / Noto Sans Arabic。
- 根字号桌面 17.5px，≤720px 为 16px。全局 `tabular-nums` 与抗锯齿。

### 间距与布局

- 容器 1180px，导航内宽 1260px，左右留白 2.25rem（≤720px 为 1.25rem）。
- 导航高 74px，sticky，`rgba(0,0,0,0.84)` + 16px 模糊 + 底部发丝线。
- 区块纵向内边距 7.5rem（移动端 4.5rem）；收尾区块 8.5rem / 7.5rem。区块标题组到内容 3.25rem，标题组最宽 72ch，hero 副标题最宽 66ch。
- hero 最小高度 `100svh - 导航高`，内容居中；其余区块左对齐。
- 发丝线栅格单元内边距 `1.5rem 1.25rem`。
- 断点：540（单列）、640（舞台紧凑）、720（根字号与留白收紧）、820（四列变两列）、900（分栏舞台堆叠）。
- 文档三栏：侧栏 19rem，正文最宽 54rem，导航高 4.5rem，段间距 2rem。

### 形状、边框、深度

- **圆角小而安静：** 4px（标签、分段、菜单项）、5px（主按钮、侧栏项）、6px（描边按钮、代码框、菜单、截图）、8px（命令条）、10px（仅舞台顶部两角）、14px（手机截图）。`999px` 只用于圆点和编号，**从不用于按钮**。
- **边框：** 结构线 1px；强调线 1.5px（强调单元格的冰蓝顶边、标注框、当前导航项左边线）；图中主线 1.8px。
- **阴影只有一个：** 弹出菜单的 `0 12px 28px rgba(0,0,0,0.72)`。其他一切都没有阴影。
- **模糊只有三处：** 导航（16px）、文档导航（14px）、展示舞台（20px）。

### 动效

- 120ms 线性：菜单项、区块顶边高光。
- 140–150ms ease：颜色、边框、背景。
- 180ms ease-out：区块亮度响应。
- 复制成功：按钮变冰蓝并换成"已复制"文案，保持 1600–1800ms 后复原。
- 悬停：文字变白，或描边从 0.18 提到 0.42 并加 0.05 白色填充。主按钮悬停降到 0.88 不透明度。
- 焦点：沉浸式页面 1px 冰蓝描边、3px 偏移；阅读页面 1.5px 白色描边。

### 图标与品牌标记

- 没有图标库。只使用少量内联 SVG 线形图标：1.3–1.4px 描边、圆头圆角、`currentColor`、11–16px（箭头、下拉 chevron、复制）。RTL 下方向箭头水平翻转。
- 状态靠几何原语表达，不靠图标：6px 圆点、6px 空心环、5px 方刻度、`>` 提示符、`+` 十字准星。
- **产品标记语法：** 4:5 的整像素栅格（`viewBox="0 0 240 300"`），由 `#EEEEEE` 的主体、`#4B4B4B` / `#2A2A2A` 两级中性内芯和**唯一一处** `#E5A03D` 琥珀缺口构成。UltraCode 的 Stepped Ultra Monolith 是这套语法的第一个实例。Quetzalcoatl 自身目前没有 logo，需要标记的位置用 Sora 600 的纯文字字标。
- **光谱字标 `.qz-wordmark`：** 字标的字母内部切成六条横向色带，色序取自 Apple 1977 年的彩虹标（绿、黄、橙、红、紫、蓝）；在 Display 尺寸下色带之间再切出细缝，取自 IBM 的八条纹标。只用于导航栏的品牌名，以及每页至多一次的大标题中的名字。用法见 `guidelines/components.md`。

## 使用

本仓库的官网（`website/`）与各端治理面（`surfaces/`）直接从本目录引入 tokens、组件与字体，不另存副本；原生端（GTK、SwiftUI、WinUI）按同一套 token 数值落到各自的样式层。

```html
<link rel="stylesheet" href="styles.css" />
<body>
  <div class="qz-optical-horizon" aria-hidden="true"></div>
  <div class="qz-grain" aria-hidden="true"></div>
  <div class="qz-page">
    <!-- 内容 -->
  </div>
  <script src="scripts/optics.js" defer></script>
</body>
```

需要随滚动响应光的区块加 `data-qz-lit`，展示舞台的容器加 `data-qz-rim`。阅读页面给地平线层加 `is-reading`，正文容器用 `.qz-prose`。

## 已知限制

- 光谱字标的色带位置按 Sora 的字形度量写死，换字体必须重新测量 `--qz-wm-top` 与 `--qz-wm-band`。
- 只打包了 Latin 子集字体；生产环境请使用 `@fontsource/sora` 与 `@fontsource/jetbrains-mono` 以获得完整子集。
- 系统只有深色，没有浅色模式，也不打算有。
- 来源网站没有表单与对话框。目前只补充定义了单行输入框 `.qz-input`（个人站点的搜索需要）；复选框、开关、下拉、多行文本和模态对话框仍未定义，需要时按本文的原则新增并回写到这里。
